# Absolute Purity for Motivic Cohomology in Dimensions at Most Three

This preprint proves absolute purity for the intrinsic motivic coefficient
$H_Y=H\mathbf Z_Y^{\mathbb A^1}=s_0KGL_Y$ in low dimensions. It also treats
invertible prime powers, regular DVR maps, and the integral cdh-to-$\mathbb A^1$
comparison.

The proof combines filtered Gysin maps and Adams operations, valuative
comparison and descent, and detection by smooth function fields.
